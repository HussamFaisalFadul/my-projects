
# Smart Productivity App 🚀

A modern productivity app built with Flutter, focused on smart task management and user productivity insights.

---

## ✨ Features

- Add, edit, and delete tasks (CRUD)
- Priority system (High, Medium, Low)
- Clean and modern UI
- Task completion tracking
- Local database (SQLite)
- State management using Riverpod

---

## 🧠 Concept

This app is not just a task manager.  
It focuses on improving productivity by helping users track their tasks and priorities effectively.

---

## 🛠️ Tech Stack

- Flutter
- Riverpod
- SQLite
